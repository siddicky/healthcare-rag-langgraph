Persisted payload marker
------------------------
The Postgres registry stores the fixed string "[redacted]" in both `input` and
`command`. `RunEngine.submit()` detects Postgres with
`isinstance(self.storage.runs, PostgresRunRegistry)`. MemoryRegistry receives
the original record, so memory-mode GET/list behavior remains unchanged.
`RunRuntime.request` always keeps the original request for graph execution.

Restart behavior
----------------
`reconcile_interrupted_runs(storage)` is Postgres-only. It changes only
`pending` and `running` rows to `interrupted`; success, error, interrupted, and
timeout rows remain untouched. The second call returns zero, proving idempotence.

GET and list routes read terminal registry records when `RunEngine.runtime` has
no entry. Join, join-stream, and cancel still use the live-runtime lookup and do
not reconstruct execution or SSE state.
