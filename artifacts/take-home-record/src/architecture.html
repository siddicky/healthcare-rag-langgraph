Three Fly apps on one private network, behind a Vercel frontend, with every vendor on a single seam.

The member never talks to the Agent Server directly: the Next.js app on nymble.site proxies the CopilotKit runtime route to hc-rag-server-prod, which reaches Weaviate and Postgres only over Fly's private 6PN. OpenAI, Supabase and LangSmith are the three remaining rented pieces, each behind one env-overridable layer.

03b · Privacy sanitizer

Presidio runs inside the server process — there is no sidecar

Identifier scrubbing is process-owned: healthcare_rag/processors/privacy.py builds a Presidio AnalyzerEngine over a spaCy NLP engine in the same Python process as the graph, on CPU, from wheels baked into the image. No second container, no network hop, nothing to fail independently.

Why "sidecar" is the wrong word here

The only sidecar in this project's history is the one that wasn't there: on 2026-08-22 the LangGraph Platform Serverless tier began injecting CORE_API_GRPC_SIDECAR=1 and expecting a Go core process on :50051 that no repo config could supply — the crash-loop that led to the clean-room server/. Presidio was deliberately kept in-process so the privacy path has no such dependency.

What the image carries
  • presidio-analyzer==2.2.364, spacy==3.8.15, en_core_web_sm 3.8.0 as a sha256-pinned wheel (pyproject.toml)
  • PRESIDIO_DEVICE=cpu set in the Dockerfile and compose; no GPU, no model download at boot
  • Runs as non-root app (uid 10001); compose runs the container read-only with /tmp on tmpfs

Portability — what moving takes
  • Run the same GHCR image (python-slim + uv, non-root app user, Presidio on CPU).
  • Restore pg_data into any PG 17 with pgvector; point DATABASE_URL.
  • Run weaviate:1.30.2 with the weaviate_data volume, or re-run make ingest from data/chunks_*.json shipped in the image.
  • Three env vars move the frontend: Supabase URL/anon key and LANGGRAPH_DEPLOYMENT_URL.

Not on Fly. The member frontend is a standard Next.js build served by Vercel at nymble.site; MCP and A2A stay unmounted (404/405), and the LangGraph Platform was left on 2026-08-22 with the diagnosis on record — the clean-room server/ is what runs here.
