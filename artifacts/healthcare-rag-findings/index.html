The result, before the journey

Accuracy alone did not decide what to ship.

In healthcare, “best” means useful, grounded, operationally sane, and able to hold a safety boundary. The experiments moved the system from a working demo to a safety-first LangGraph runtime.

01

The assignment shaped the lens

Safety was required. Measurement made the judgment defensible.

The brief asked for healthcare restraint first, then two or three deliberate directions. The work converged on three connected bets.

Direction 4 · required

Enforce what the assistant must refuse, what data it must not retain, and when it must redirect.

Direction 3 · measure

Build a regression safety net across quality, grounding, retrieval, safety, latency, and cost.

Direction 5 · question the shape

Replace speculative partial-answer selection with synthesis, then port the measured behavior into LangGraph.

03

The experiment journey

Each variant answered a different engineering question.

The winning architecture emerged from rejected model choices, a decomposition failure, a synthesis fix, and explicit safety enforcement.

  1. Original

    GPT-4o mini + GPT-4o validator

    Established the 45-example core baseline, then a 41-example holdout split.

    Working demo; unsafe boundary.

  2. Model migration

    Luna + Terra

    Improved some holdout quality, but Luna decomposed aggressively and multiplied speculative work.

    More calls, more branches, flat quality.

  3. Rejected

    Luna + Luna

    Using Luna as validator removed too much supported content.

    Correctness fell to 0.55.

  4. Architecture fix

    Capped decomposition + synthesis

    Subqueries gathered evidence only; merged documents produced one answer to the original question.

    Correctness rose to 0.89.

  5. Required direction

    Runtime safety gate

    PHI scrubbing, deterministic escalation checks, one classifier call, and plain refusal templates moved safety ahead of retrieval.

    Advice leakage fell 52% → 4%.

  6. Final runtime

    LangGraph StateGraph

    Ported the measured pipeline into explicit nodes, conditional edges, bounded fan-out, checkpointed history, and a sealed parity gate.

    One runtime; observable decisions.

05

What graph-final consists of

A safety-first graph, with bounded work and one synthesized answer.

Luna runs the main stages, Terra validates citations, and Weaviate supplies hybrid retrieval over the two monographs.

  1. Safety gateScrub PHI, classify, and short-circuit emergencies, personal advice, out-of-scope requests, and instruction overrides.
  2. Clarify + conversation contextRun in parallel, using scrubbed checkpointed history.
  3. Complex-only decompositionAlways keep the parent query; add at most three evidence-gathering subqueries.
  4. Hybrid retrieval + mergeSearch Lipitor and Metformin, then deduplicate by document ID.
  5. Retrieval evaluationAllow one bounded gap-fill round when evidence is insufficient.
  6. Generate onceAnswer the original question over the merged evidence.
  7. Validate + follow upStructure citations with Terra, then generate follow-ups only for validated answers.
  8. FinalizePersist only the scrubbed conversation pair and return graph telemetry.

Short-circuit path

Refusals return deterministic templates without retrieval or answer generation. Follow-ups are empty.

Synthesis is implicit

There is no “pick the best sub-answer” stage. Every retrieval branch merges before one generation call.

Configuration

gpt-5.6-luna main · gpt-5.6-terra validator · reasoning effort none · all stages enabled.

10

The release cut

Legacy deleted in one commit. Privacy became process-owned.

The LangGraph StateGraph is now THE runtime. A process-owned sanitizer — Presidio 2.2.364, spaCy en_core_web_sm, and deterministic CA/US healthcare-ID patterns — scrubs identifiers before any model sees them.

−4,307lines of legacy orchestrator and pipeline plumbing removed
52files changed in one revertable commit (3435caf)
259tests green at the end of the cut
1runtime remains: the LangGraph StateGraph
  1. Scrub before classificationIdentifiers leave the query and history before the safety gate runs — and stay scrubbed even when the gate is ablated.
  2. Sanitize at every sinkEvery model-authored query is scrubbed at its next sink; answers and follow-ups are scrubbed again at finalize.
  3. Spans advise, never editModel-proposed spans can influence metadata but never mutate text.
  4. Fail closedErrors return raw-free error codes; no unsanitized text escapes.
  5. Preserve clinical codesRxCUI, NDC, DIN, LOINC, and SNOMED survive scrubbing so dosing facts stay answerable.

Safe Harbor as inventory, not claim

HIPAA's 18-identifier list is a coverage checklist: 15/18 covered or deliberately diverged (cue-gated dates), 2 not applicable to a text pipeline, 1 inherently heuristic.

The audit found the gap

The vehicle-identifier hole was found by this audit and closed with a cue-bound VIN/plate pattern — with clinical-text negative tests pinning that “platelet count” must not fire.

01

The shipped surface

02

The accepted cost

The validator costs ~90% of pipeline spend and ~5s p50 — accepted as-is (D15). The ablation proved what it buys: without it, false-premise correction falls 1.0 → 0.875 and hallucinated rises +0.08. If cost ever matters, the lever is a cheaper validator — never removal.

03

The open boundary

Safety drift 0.409 still trails the pre-graph 0.364. The next pass holds refusal state across turns instead of reclassifying each turn in isolation, and treats judge deltas within ±0.05 as noise until they repeat.
